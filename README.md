# HabitTracker - Система отслеживания привычек

## 📋 Описание проекта

**HabitTracker** — это веб-приложение для отслеживания привычек, разработанное как курсовой проект студента 2 курса. Система позволяет пользователям создавать привычки, отслеживать их выполнение и мотивировать себя через социальные функции.

## 🎯 Основные возможности

- ✅ **Регистрация и авторизация** пользователей
- ✅ **Создание и управление** привычками
- ✅ **Отслеживание прогресса** с визуализацией
- ✅ **Социальные функции** (поиск друзей, уведомления)
- ✅ **Адаптивный дизайн** для всех устройств
- ✅ **Безопасное хранение** паролей

## 🛠️ Технологический стек

- **Backend:** ASP.NET Core 8.0, C#
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
- **База данных:** SQLite
- **ORM:** Entity Framework Core
- **Аутентификация:** Cookie-based authentication
- **Инструменты:** Visual Studio Code, Git

## 🚀 Быстрый старт

### Предварительные требования

- .NET 8.0 SDK
- Git

### Установка и запуск

1. **Клонирование репозитория:**
   ```bash
   git clone <repository-url>
   cd HabitTracker
   ```

2. **Запуск с помощью Makefile:**
   ```bash
   make setup
   ```

3. **Или ручная установка:**
   ```bash
   dotnet restore
   dotnet ef database update
   dotnet run
   ```

4. **Открыть в браузере:**
   ```
   http://localhost:5216
   ```

## 🎮 Использование

### Регистрация и вход
1. Перейдите на страницу регистрации
2. Создайте аккаунт с уникальным именем пользователя
3. Войдите в систему

### Создание привычек
1. Перейдите в раздел "Мои привычки"
2. Нажмите "Добавить привычку"
3. Введите название и описание
4. Нажмите "Создать"

### Отслеживание прогресса
1. На главной панели отображается недельный прогресс
2. Нажмите на кнопку рядом с привычкой для отметки выполнения
3. Просматривайте статистику в календарном виде

### Социальные функции
1. Найдите друзей через поиск
2. Отправьте запрос в друзья
3. Принимайте или отклоняйте запросы в уведомлениях
