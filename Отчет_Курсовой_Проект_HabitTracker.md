## ВВЕДЕНИЕ

В современном мире формирование полезных привычек является ключевым фактором для достижения успеха в различных сферах жизни. Однако многим людям сложно самостоятельно отслеживать свой прогресс и поддерживать мотивацию. 

**Цель проекта** — разработка веб-приложения для отслеживания привычек, которое поможет пользователям формировать полезные привычки, отслеживать свой прогресс и мотивировать себя через социальные элементы.

**Задачи проекта:**
- Создать систему регистрации и авторизации пользователей
- Реализовать функциональность создания и управления привычками
- Разработать систему отслеживания прогресса с визуализацией
- Добавить социальные функции (поиск друзей, уведомления)
- Обеспечить удобный и интуитивный пользовательский интерфейс

**Актуальность проекта** обусловлена растущим интересом к саморазвитию и необходимости в инструментах, помогающих формировать полезные привычки.

## ТЕХНИЧЕСКОЕ ЗАДАНИЕ

### 2.1 Назначение и цели создания системы

Система HabitTracker предназначена для:
- Отслеживания ежедневных привычек пользователей
- Визуализации прогресса в виде календарей и графиков
- Создания социальной сети для мотивации через друзей
- Предоставления статистики и аналитики привычек

### 2.2 Требования к системе

**Функциональные требования:**
- Регистрация и авторизация пользователей
- Создание, редактирование и удаление привычек
- Отметка выполнения привычек по дням
- Просмотр статистики и прогресса
- Поиск и добавление друзей
- Система уведомлений о запросах в друзья
- Визуализация прогресса в календарном виде

**Нефункциональные требования:**
- Время отклика системы: не более 2 секунд
- Поддержка современных веб-браузеров
- Адаптивный дизайн для мобильных устройств
- Безопасное хранение паролей (хэширование)
- Защита от CSRF-атак

### 2.3 Технологический стек

- **Backend:** ASP.NET Core 8.0, C#
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
- **База данных:** SQLite
- **ORM:** Entity Framework Core
- **Аутентификация:** Cookie-based authentication
- **Инструменты разработки:** Visual Studio Code, Git

## АНАЛИЗ ТРЕБОВАНИЙ

### 3.1 Анализ предметной области

Предметная область включает:
- **Пользователи** — люди, желающие формировать полезные привычки
- **Привычки** — регулярные действия, которые пользователь хочет выполнять

5. **FriendRequest** — запрос в друзья

### 3.3 Пользовательские сценарии

1. **Регистрация нового пользователя**
2. **Создание первой привычки**
3. **Отметка выполнения привычки**
4. **Просмотр прогресса за неделю/месяц**
5. **Поиск и добавление друзей**
6. **Принятие/отклонение запросов в друзья**

## ПРОЕКТИРОВАНИЕ СИСТЕМЫ

### 4.1 Архитектура системы

Система построена по архитектуре **MVC (Model-View-Controller)** с использованием **Razor Pages**:

```
HabitTracker/
├── Models/          # Модели данных
├── Data/           # Контекст базы данных
├── Pages/          # Razor Pages (View + Controller)
├── wwwroot/        # Статические файлы
└── Migrations/     # Миграции базы данных
```

### 4.2 Диаграмма базы данных

```
Users (1) ←→ (N) Habits (1) ←→ (N) HabitCompletions
   ↓
Friends (M:N через FriendRequests)
```

### 4.3 Структура страниц

1. **Index** — главная страница с приветствием
2. **Login/Register** — авторизация и регистрация
3. **Dashboard** — основная панель с прогрессом
4. **MyHabits** — управление привычками
5. **FindFriends** — поиск друзей
6. **Notifications** — уведомления
7. **HabitDetails** — детальная информация о привычке

### 4.4 Дизайн пользовательского интерфейса

- **Минималистичный дизайн** с акцентом на функциональность
- **Цветовая схема:** синий (#3498db), зеленый (#27ae60), серый (#7f8c8d)
- **Адаптивная верстка** для различных устройств
- **Интуитивная навигация** с понятными иконками и текстом

```csharp
public class Habit
{
    public int Id { get; set; }
    [Required]
    public string Name { get; set; } = string.Empty;
    public string? Description { get; set; }
    public int UserId { get; set; }
    public User User { get; set; } = null!;
    public List<HabitCompletion> Completions { get; set; } = new();
}
```

### 5.3 Алгоритмы и методы

#### 5.3.1 Хэширование паролей

```csharp
private static string HashPassword(string password)
{
    using var sha256 = SHA256.Create();
    var hashedBytes = sha256.ComputeHash(Encoding.UTF8.GetBytes(password));
    return Convert.ToBase64String(hashedBytes);
}
```

#### 5.3.2 Расчет прогресса привычек

```csharp
public bool IsCompletedToday(int habitId)
{
    var today = DateTime.Today;
    return Habits
        .FirstOrDefault(h => h.Id == habitId)?
        .Completions
        .Any(c => c.Date.Date == today && c.Completed) ?? false;
}
```
